# PowerShell Scripts Library

Welcome to the PowerShell Scripts Library — a curated collection of PowerShell scripts created and maintained by [Ahad Alam](https://github.com/Ahad621).
This repository includes practical tools and utilities for:

* 🔧 Endpoint management using Microsoft Intune (Detection & Remediation)
* 🤖 Automation and system maintenance scripting
* 🧪 Configuration compliance and health checks

All scripts are designed to be production-friendly and easy to adapt.

---

## 📁 Repository Structure

```
powershell-scripts-library/
├── intune-remediation/         # Scripts for Intune detection & remediation
│   └── <script-name>/          # Each pair in its own subfolder
│       ├── detect-*.ps1
│       ├── remediate-*.ps1
│       └── README.md
├── automation/                 # Standalone automation & utility scripts
│   └── <task-name>/            # Organized by purpose
│       ├── *.ps1
│       └── README.md
├── LICENSE
└── README.md
```

---

## ✅ Getting Started

1. Clone this repository:

```bash
git clone https://github.com/Ahad621/powershell-scripts-library.git
cd powershell-scripts-library
```

2. Navigate to the folder of interest (`intune-remediation` or `automation`).

3. Review the script’s individual README for usage details.

---

## 🛠️ Requirements

* PowerShell 5.1 or later (some scripts may require PowerShell Core)
* Appropriate administrative permissions, depending on the task
* For Intune scripts: Microsoft Endpoint Manager integration or testing environment
